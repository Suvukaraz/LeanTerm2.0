# LeanTerm 2.1.0

LeanTerm 2.1 makes LeanTerm and LeanEdit fit into the desktop: their own taskbar entries and icons, drag and drop with file managers in both directions, and many fixes in dialogs, menus and LeanEdit.

## Install

- **Linux (x86_64)**: `curl -fsSL https://raw.githubusercontent.com/Suvukaraz/LeanTerm2.0/main/install.sh | sh` (the `.deb` package on Debian and Ubuntu, the archive elsewhere), or `leanterm_2.1.0_amd64.deb` from this release.
- **Windows 10 or later**: `leanterm_2.1.0_windows_amd64_setup.exe` (not code-signed yet: SmartScreen asks once).

## New

- **Drag and drop**
  - Files from a file manager onto the file browser go into the folder under the pointer: uploaded over SFTP, copied on local tabs. Elsewhere in LeanTerm they open in LeanEdit; on LeanEdit's window they open as tabs. Works on X11, Wayland and Windows.
  - Rows dragged onto a folder (or `..`) in the file browser are moved there.
  - Rows dragged out of the window go to the desktop or a file manager (remote files are downloaded first).
- **LeanEdit as an application of its own** – its own taskbar entry and icon on KDE, GNOME and Windows, also when LeanTerm opens it for remote files. Windows gets `leanedit.exe`, with its own entry in *Open with*.
- **KWrite-style word wrap** – wrapped lines start at their line's indentation, with wrap markers next to the line numbers (two new settings, on by default).
- **Tooltips** on the icon buttons of LeanTerm and LeanEdit.
- **Movable dialogs** – the settings and all other dialogs can be dragged by their title bar.

## Fixed

- LeanEdit opened from KDE ("Open with", double-click) seemed to close at once on Wayland: the file went to a running LeanEdit window that could not come to the front. It comes to the front now, and new windows use the desktop's activation token.
- The window icon was a placeholder on KDE: the windows now use the application ids of their `.desktop` files.
- The terminal engine could not be switched to the pure Go engine (the setting was rejected when saving).
- The About dialog: the logo covered the text and the Close button.
- LeanEdit's syntax selector in the status bar: its language lists opened outside the window.
- Menus: submenus stay inside the window and flip to the left, long menus scroll, a right click elsewhere reopens the menu there, clicking the open menu's title closes it, chosen items act at once, and the keyboard focus returns after a menu.
- Dragging in LeanEdit's minimap scrolled too far; the wheel over the minimap scrolls like over the text.
- SFTP: the channel of a closed tab was never closed, and the browser kept a dead channel after a reconnect.

## Upgrading

- The configuration format is unchanged (two new LeanEdit settings with defaults).
- The Windows installer replaces 2.0.0; LeanEdit's shortcuts now start `leanedit.exe`.
