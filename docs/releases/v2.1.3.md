# LeanTerm 2.1.3

LeanTerm 2.1.3 fixes regressions in the menus of 2.1.1 and the LeanEdit context menus of 2.1.2.

## Install

- **Linux (x86_64)**: `curl -fsSL https://raw.githubusercontent.com/Suvukaraz/LeanTerm2.0/main/install.sh | sh` (the `.deb` package on Debian and Ubuntu, the archive elsewhere), or `leanterm_2.1.3_amd64.deb` from this release.
- **Windows 10 or later**: `leanterm_2.1.3_windows_amd64_setup.exe` (not code-signed yet: SmartScreen asks once).

## Fixes

- **Menus: arrow keys work again while the mouse pointer rests on the menu.** Since 2.1.1 the row under the pointer took the selection back in every frame, so Up/Down did nothing, for example in a context menu opened under the pointer. The pointer now moves the selection only when it enters another row.
- **LeanEdit: a right click no longer selects text.** Without a selection, a right click selected everything from the old cursor position to the click. It now only moves the cursor there, as a left click does.
- **LeanEdit: the right-click menu belongs to the tab that was clicked**, also when the tab bar is scrolled (many open tabs). Before, the menu could act on a different tab.
- **LeanEdit: clicks on the word completion list and the fold markers** no longer also reach the text underneath.
- **LeanEdit: "Close All Tabs" and "Close Other Tabs"** no longer read the tab list from a background thread while the window changes it.
