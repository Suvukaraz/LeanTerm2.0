# LeanTerm 2.0.0

LeanTerm 2.0 is a rewrite of the user interface. The application is now a native Go program with the [Gio](https://gioui.org) GUI toolkit: no embedded browser engine and no JavaScript runtime. Connections, sessions, the file browser and the configuration files keep their formats, so existing setups carry over.

## Highlights

- **Native GUI** – one Go binary (`leanterm`) draws the connection tree, the tabbed terminals, the file browser and the dialogs itself, on Linux (Wayland and X11) and Windows.
- **libghostty terminal engine** – the terminal core of [Ghostty](https://ghostty.org) (libghostty-vt) is used for terminals by default in the release builds. The pure Go engine stays available.
- **LeanEdit** – the editor, also installed as its own application (`leanedit`):
  - code folding for many languages,
  - word completion,
  - *Go to Symbol* to jump to functions and types of the file,
  - tabs, bookmarks, a minimap and reloading of files changed by other programs.
- **Packages** – `.deb` package, Linux archive with the `install.sh` installer (`curl -fsSL https://raw.githubusercontent.com/Suvukaraz/LeanTerm2.0/main/install.sh | sh`) and a Windows installer.

## Upgrading

- The configuration format is unchanged; older files are migrated when LeanTerm starts.
- The Windows installer replaces an installed version of LeanTerm.
- The Linux packages install `leanterm` and `leanedit`.

## Known limitations

- The Windows installer is not code-signed yet.
- The Ghostty engine needs the release builds or a local build with `-tags ghostty`.
