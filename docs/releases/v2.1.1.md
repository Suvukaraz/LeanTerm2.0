# LeanTerm 2.1.1

LeanTerm 2.1.1 improves menu and dropdown responsiveness, fixes hover highlighting artifacts, and updates documentation with rich interface screenshots.

## Install

- **Linux (x86_64)**: `curl -fsSL https://raw.githubusercontent.com/Suvukaraz/LeanTerm2.0/main/install.sh | sh` (the `.deb` package on Debian and Ubuntu, the archive elsewhere), or `leanterm_2.1.1_amd64.deb` from this release.
- **Windows 10 or later**: `leanterm_2.1.1_windows_amd64_setup.exe` (not code-signed yet: SmartScreen asks once).

## Improvements & Fixes

- **Menu Responsiveness & Hover Tracking**
  - Resolved stuttery/laggy hover feedback in context and dropdown menus by evaluating pointer events immediately before layout.
  - Eliminated hover artifacts where two or more entries remained highlighted in blue at the same time.
  - Enhanced submenu transitions: parent items remain cleanly selected while hovering child menus, and submenus close immediately when switching to another parent item.
  - Mouse wheel scrolling within long menus now invalidates and redraws immediately.
  - Menu rows now display a standard arrow cursor (`pointer.CursorDefault`) instead of inheriting I-beam text cursors when opened over terminals or editors.
- **Combobox & Dropdown Lists**
  - Fixed an issue where the currently active value and hovered items were both rendered with solid blue selection backgrounds simultaneously.
  - Smooth hover tracking with immediate frame invalidation for dropdown options.
- **Documentation & UI Showcase**
  - Updated README with interface screenshots showcasing LeanTerm with connections tree, SFTP browser and remote terminal (Ghostty), file browser with local shell (VT engine), and the standalone LeanEdit editor with full syntax highlighting and minimap.
