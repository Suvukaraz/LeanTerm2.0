# LeanTerm 2.1.2

LeanTerm 2.1.2 adds native right-click context menus across LeanEdit for the editor body, tab bar, and individual tabs.

## Install

- **Linux (x86_64)**: `curl -fsSL https://raw.githubusercontent.com/Suvukaraz/LeanTerm2.0/main/install.sh | sh` (the `.deb` package on Debian and Ubuntu, the archive elsewhere), or `leanterm_2.1.2_amd64.deb` from this release.
- **Windows 10 or later**: `leanterm_2.1.2_windows_amd64_setup.exe` (not code-signed yet: SmartScreen asks once).

## Improvements & Fixes

- **LeanEdit Editor Context Menu**
  - Right-clicking within the editor text area now opens a comprehensive context menu featuring Undo, Redo, Cut, Copy, Paste, Delete, Select All, Find…, Replace…, Go to Line…, Highlighting submenu, and Word Wrap toggle.
  - Right-clicking with an active selection preserves the selection range with Cut and Copy enabled. Right-clicking without a selection repositions the text caret directly to the clicked line and column.
- **Tab & Tab Bar Context Menus**
  - Right-clicking any editor tab displays a context menu with Close, Close Other Tabs, Close All Tabs, Save, Save As…, Copy Path, and Reload.
  - Added "Close Others" / "Close Other Tabs" support to both the tab context menu and the File menu.
  - Right-clicking empty space on the tab bar or the placeholder view opens quick access to New Document and Open File….
- **Menu Focus & Dismissal**
  - Context menus dismiss cleanly when clicking elsewhere or selecting top-level menus, reliably restoring keyboard focus to the editor view.
