# PureTerm 2.1.4

**LeanTerm** is now **PureTerm**, and the integrated & standalone code editor **LeanEdit** is now **PureEdit**. Version 2.1.4 also resolves the Windows console window popup and significantly speeds up Windows startup.

## Install

- **Linux (x86_64) — one-line installer**:
  ```sh
  curl -fsSL https://raw.githubusercontent.com/Suvukaraz/PureTerm/main/install.sh | sh
  ```
  *(Uses the `.deb` package on Debian/Ubuntu and the portable archive on Fedora, openSUSE, Arch, etc.; see [install.sh](https://raw.githubusercontent.com/Suvukaraz/PureTerm/main/install.sh).)*
- **Debian / Ubuntu (`.deb`)**: [pureterm_2.1.4_amd64.deb](https://github.com/Suvukaraz/PureTerm/releases/download/v2.1.4/pureterm_2.1.4_amd64.deb)
- **Windows 10 (1809) or later (`.exe`)**: [pureterm_2.1.4_windows_amd64_setup.exe](https://github.com/Suvukaraz/PureTerm/releases/download/v2.1.4/pureterm_2.1.4_windows_amd64_setup.exe) *(not code-signed yet: SmartScreen asks once)*

## Changes

- **Renamed to PureTerm & PureEdit**:
  - Repository, binaries (`pureterm` / `pureterm.exe` and `pureedit` / `pureedit.exe`), desktop entries (`org.pureterm.PureTerm`, `org.pureterm.PureEdit`), and packages updated to **PureTerm** and **PureEdit**.
  - Existing LeanTerm configuration folders (`~/.config/leanterm`, `%APPDATA%\LeanTerm`) and keyring entries (`org.leanterm.app`) are migrated automatically on first launch, and the `.deb` package replaces `leanterm` cleanly.
- **Windows: No more command prompt window on launch**:
  - Fixed CGO cross-linking with `zig cc` (`-Wl,--subsystem,windows`), which previously left `Subsystem = Windows CUI` instead of `Windows GUI` on both `pureterm.exe` and `pureedit.exe`. Both Windows binaries are now built and verified as `IMAGE_SUBSYSTEM_WINDOWS_GUI`.
- **Windows: Much faster startup for PureEdit and PureTerm**:
  - Fixed `PureEdit` scanning and fully parsing every font file in `C:\Windows\Fonts` when using the default `"Monospace"` font setting.
  - Replaced full-directory font parsing on Windows with Windows Registry lookups and lightweight SFNT `'name'`-table reads (`io.ReaderAt`), parsing only the requested font faces.
  - Added single-face `.ttc` loading (`opentype.ParseIndex`) and parallel font loading/parsing for startup UI and CJK/emoji fallback fonts.
